# 智能数据分析助手｜分段演示视频完整脚本

## 一、成片目标

- 建议总时长：5～6 分钟。
- 建议比例：UI 产品演示约 2 分钟，CLI 与技术讲解约 3～4 分钟。
- 核心定位：这不是一个只有网页界面的数据工具，而是一套可被 UI、CLI 等入口复用的本地数据分析引擎。
- 推荐采用 8 个独立片段录制。每段失败只重录当前片段，后期按编号顺序拼接。

## 二、录制前准备

### 1. 桌面与隐私

- 关闭微信、邮箱和其他会弹通知的软件。
- 浏览器只保留智能数据分析助手页面。
- 不展示 `.env`、API Key、个人聊天窗口或其他私人文件。
- 浏览器缩放建议设为 90% 或 100%。
- 终端字体适当放大，保证命令和结果可以看清。

### 2. 准备演示数据

演示文件：

```text
analyzer\evals\data\sales_sample.csv
```

数据特征：原始文件 5040 行、11 列，其中包含 40 行重复数据，并包含少量缺失值，适合展示清洗与分析能力。

### 3. 准备 CLI 命令

正式录制前，在项目目录打开 `cmd`，先执行 `cls` 清空窗口。录制时使用：

```cmd
.\.venv\Scripts\python.exe -m analyzer analyzer\evals\data\sales_sample.csv -q "华东地区的销售总额是多少？" --show-code
```

预期核心结果：

```text
数据：5040 行 × 11 列 | 模型：zhipu/glm-4-flash
华东地区的销售总额为：26,143,076.33 元
result = df[df['地区'] == '华东']['销售额'].sum()
```

模型输出的自然语言措辞可能略有不同，只要数值和生成代码正确即可。

## 片段 07｜安全架构与工程亮点

**文件名：** `07_安全架构.mp4`

**建议时长：** 55～75 秒

**画面：** 可以停留在 README 的沙箱设计部分，或使用一张简单架构图。

### 逐字口播

> 这个项目最重要的工程设计是把模型生成的代码视为不可信输入。第一层是 AST 静态白名单，禁止 import、文件读写、动态执行、危险标识符和 dunder 属性访问，并限制 pandas 与 NumPy 可调用的方法。第二层是动态隔离：代码在一次性子进程中运行，默认设置 20 秒超时和 1GB 内存上限，父进程负责监控并终止失控进程。父进程可以把可信数据传给子进程，但子进程只通过 JSON 返回结果，不反序列化执行过不可信代码的产物。这样即使模型生成错误代码，也不会直接污染主应用。

### 可选补充口播

> 我没有把它描述成绝对安全的 Python 沙箱。对于解释器级逃逸仍然存在残余风险，因此生产环境还可以进一步替换为容器或更强的操作系统级隔离。

### 本段检查

- 不要逐行念代码。
- 始终围绕“为什么这样设计”讲，而不是堆技术名词。

## 六、出错时如何处理

- 说错一句：停两秒，从当前句重新说，后期剪掉错误部分。
- 页面加载慢：继续等，后期剪掉等待时间。
- 模型请求失败：只重录智能问答或 CLI 片段。
- 图表未加载完成：等待三张图完整出现后重新录制该片段。
- 出现红色报错：停止当前片段并记录报错，不要带着错误继续录。
- 鼠标点错页面：停两秒，回到正确页面后重新开始当前片段。
