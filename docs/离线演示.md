# 无模型的执行链路演示

在仓库根目录安装 requirements.txt 后执行：

```bash
python scripts/demo_offline.py
```

三行合成数据：地区A销售额10、20，地区B销售额5。固定的 Pandas 代码进入实际子进程，结果必须是A=30、B=5；随后确认文件读取代码被静态校验拒绝。

脚本不调用模型，不使用用户文件。它验证真实执行链路和一个拒绝路径，不证明模型能理解自然语言，也不证明沙箱抵御所有攻击。

要验证模型生成，使用 README 的 CLI 示例并自行配置模型。默认开启脱敏；用户问题、字段名、数值、生成代码与错误信息仍可能外发。
